    Add an admin

      About the shared password Every admin signs in with their own email and the same password. The password is stored only in Supabase, never in this page or in the database.
      1. Open your Supabase project sargotsav-2026.
      2. Go to Edge Functions → Secrets.
      3. Set ADMIN_PASSWORD to a password of 10 or more characters.
      To change it, edit the same secret. New sign-ins use the new password straight away. Removing someone from the list stops them seeing contestants even if they know the password.
